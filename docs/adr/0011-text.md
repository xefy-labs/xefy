# 0011. Text: Skia's paragraph module, UTF-8 byte offsets

Status: accepted (2026-11-12)

## Decision
- Shaping, line breaking, bidirectional text and font fallback come from Skia's `skparagraph`
  (HarfBuzz and ICU, both built from Skia's pinned sources). Flutter's `txt/` is not used.
- A paragraph is built once per distinct (text, style, width) and cached by the framework,
  keyed by node id.
- Every text position in the framework and across the ABI is a UTF-8 byte offset, because
  Prismio strings are UTF-8. The engine converts to and from Skia's UTF-16 indices.
- Cursor movement and deletion move by grapheme cluster; the engine answers "next/previous
  grapheme boundary" rather than the framework reimplementing segmentation.
- Text editing logic (selection, word movement, undo) is ported from Flutter's `services` and
  `widgets/editable_text` behaviour into Prismio.
- IME composition is engine-side; v0 delivers committed text only.

## Consequences
The framework never indexes a string by code unit. An editing bug that splits a character is
an engine bug in boundary reporting, with one place to fix it.
