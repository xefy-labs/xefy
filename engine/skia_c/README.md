# engine/skia_c

Planned home of the C++ shim that implements the drawing and text functions of the C ABI
(`engine/abi/xefy_engine.h`) on Skia. Skia does all 2D drawing and owns the window surface.
Text shaping and layout will use Skia's `skparagraph`.

This directory is empty for now. The shim has not been written yet.
